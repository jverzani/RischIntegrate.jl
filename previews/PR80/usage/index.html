    Usage#

    integrate(ex, x)                 # indefinite integral
integrate(ex, x, y, …)           # iterated: ∫ … (∫ ex dx) dy …
integrate(ex, (x, a, b), …)      # definite: F(b) - F(a)

    The answer is a term of the same package as ex (without a constant of integration), or an IntegralWithRootSums when the logarithmic part needs the roots of a polynomial of degree greater than 2.

    SymEngine.jl#

    using SymEngine: @vars
using RischIntegrate: integrate
@vars x y

integrate(x * exp(x), x)
    \[e^{x} \left( -1 + x \right)\] 
    integrate(1 / (1 + cos(x)^2), x)          # continuous on the whole real line
    \[\frac{1}{2} \sqrt{2} x + \frac{-1}{2} \sqrt{2} \arctan\left( \frac{\sin\left( 2 x \right)}{3 + 2 \sqrt{2} + \cos\left( 2 x \right)} \right)\] 
    integrate(sqrt(x) / (x - 1), x)           # radicals by substitution
    \[2 \sqrt{x} - \log\left( 1 + \sqrt{x} \right) + \frac{1}{2} \log\left( \left( -1 + \sqrt{x} \right)^{2} \right)\] 
    integrate(x * y, x, y)                     # iterated
    \[\frac{1}{4} x^{2} y^{2}\]

    SimpleExpressions.jl#

    using SimpleExpressions
using RischIntegrate: integrate
@symbolic x

integrate(log(x)^2, x)
    \[2 x -2 x \log\left( x \right) + x \left( \log\left( x \right) \right)^{2}\] 
    integrate(1 / (x * sqrt(x^2 + 1)), x)
    \[\frac{\log\left( \left( -1 + \sqrt{1 + x^{2}} + x \right)^{2} \right)}{2} -1 \log\left( 1 + \sqrt{1 + x^{2}} + x \right)\]

    SymbolicUtils.jl#

    SymbolicUtils terms implement the TermInterface methods and are integrated directly. Constants such as sqrt(2) are kept exact (they are built with TermInterface.maketerm; SymbolicUtils would otherwise evaluate sqrt(2) to a floating point number):

    using SymbolicUtils: @syms
using RischIntegrate: RischIntegrate, integrate
@syms x::Real a::Real

integrate(1 / (x^2 + 2), x)
    \[\frac{1}{2} \arctan\left( \frac{1}{2} \sqrt{2} x \right) \sqrt{2}\] 
    integrate(exp(a * x) * sin(x), x)
    \[\frac{ - \cos\left( x \right) e^{a x}}{1 + a^{2}} + \frac{a e^{a x} \sin\left( x \right)}{1 + a^{2}}\]

    Symbolics.jl#

    Symbolics wraps its SymbolicUtils terms in Num, which does not implement the TermInterface methods: unwrap the integrand and the variable, and wrap the answer again.

    using Symbolics
using RischIntegrate: integrate
@variables x

∫(f, x) = Num(integrate(Symbolics.unwrap(f), Symbolics.unwrap(x)))
∫(1 / (x^2 + 2), x)       # (1//2)*atan((1//2)*sqrt(2)*x)*sqrt(2)

    Giac.jl#

    Giac terms implement the TermInterface methods (through Giac's TermInterface extension) and are integrated directly; Giac's ln is read as log:

    using Giac
using RischIntegrate: integrate
@giac_var x

integrate(log(x)^2, x)      # 2*x-2*x*ln(x)+x*ln(x)^2
integrate(1 / (x^2 + 2), x) # 1/2*sqrt(2)*atan(sqrt(2)/2*x)

    Expr and other term types#

    The keywords build and lift say how the answer is built: build(op, args...) makes the term for the function op (+, *, sqrt, log, …) applied to the terms args, and lift(n) turns a Julia number into a term. By default operations are called as functions. For Expr:

    using RischIntegrate: integrate
build(op, args...) = Expr(:call, nameof(op), args...)

integrate(:(x * exp(x)), :x; build = build, lift = identity)
    :((-1 + x) * exp(x))

    The macro @integrate does this without quoting, so no symbolic package is needed ($v puts in the value of a variable v):

    using RischIntegrate
@integrate(x * exp(x), x)
    :((-1 + x) * exp(x))
    @integrate(sin(x), (x, 0, π))
    2.0

    The bounds of a definite integral are evaluated, so a bound in the variable of a later integral is quoted. Over the region between y = x² and y = x for 0 ≤ x ≤ 1:

    @integrate(x + y, (y, :(x^2), :x), (x, 0, 1))
    0.15

    Non-elementary integrals#

    Integrals that can be written with the special functions of SpecialFunctions.jl (expinti, sinint, cosint, erf, erfi) and PolyLog.jl (li2) are returned that way, when the term type has methods for them (SymbolicUtils does):

    integrate(exp(-x^2), x)
    \[\frac{1}{2} \mathrm{erf}\left( x \right) \sqrt{\pi}\] 
    integrate(sin(x) / x, x)
    \[\mathrm{sinint}\left( x \right)\] 
    integrate(log(x) / (1 + x), x)
    \[\mathrm{li2}\left( \frac{1}{1 + x} \right) + \frac{1}{2} \left( \log\left( 1 + x \right) \right)^{2}\]

    If the term type has no method for the special function (e.g. sinint(x) for a symbolic x), the call raises its MethodError. NotElementary is thrown when the integral is proved to be non-elementary and has no such form:

    try
    integrate(exp(x) / log(x)^2, x)
catch e
    sprint(showerror, e)
end
    "NotElementary: no elementary antiderivative: the residues of the integrand are not constants (residue criterion)"

    and RischNotImplemented when the integrand lies outside the cases implemented, for example a square root of a logarithm:

    try
    integrate(sqrt(log(x)), x)
catch e
    sprint(showerror, e)
end
    "RischNotImplemented: radical of a non-rational expression (log(x)): only radicals of rational functions of x are supported"

    Non-elementary algebraic integrals: ₂F₁#

    For a radical of a binomial α + βxⁿ (α > 0), the part of a non-elementary integral that is left after the algebraic and logarithmic parts is written with Gauss's hypergeometric function (HypergeometricFunctions._₂F₁), as Rubi does: ∫ xᵐ(α + βxⁿ)^q dx = α^q x^(m+1)/(m+1) ₂F₁(-q, (m+1)/n; (m+1)/n + 1; -βxⁿ/α). The answer is an IntegralWithRootSums (the ₂F₁ terms are evaluated numerically):

    F = integrate(sqrt(x^3 + 1), x)
    (2/5)*x*sqrt(1 + x^3) + (3/5)*x*₂F₁(1/2, 1/3; 4/3; -x^3)
    F(2.0) - F(1.0)
    2.129861292662698

    Set RischIntegrate.HYP_ANSWERS[] = false to get NotElementary instead.

    RootSums#

    When the residues of the logarithmic part are algebraic of degree greater than 2, the answer is an IntegralWithRootSums: an elementary term plus sums over the roots of a polynomial. It can be evaluated numerically; the logarithms are continued along the real line, so F(b) - F(a) is a definite integral:

    F = integrate(1 / (x^5 + x + 1), x)
    (5/21)*sqrt(3)*atan(sqrt(3)*(1/3 + (2/3)*x)) + (-1/14)*log(1 + x + x^2) + RootSum(α -> α*log(x + (-644/25*α^2 + 253/25*α + 16/25)), α^3 - 1/7*α^2 - 12/161*α - 1/161 = 0)
    F(2.0) - F(1.0)
    0.12705252340768314
