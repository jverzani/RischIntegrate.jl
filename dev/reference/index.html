    RischIntegrate.integrate

    source 
    integrate(ex, xabs::Tuple)

    Definite integral of a symbolic expression over variable x from a to b.

    Example

    @symbolic x
out = integrate(sin(x), (x, 0, pi))
out, simplify(out)

    RischIntegrate.@integrate

    source 
    @integrate(f, x)
@integrate(f, x, y, …)
@integrate(f, (x, a, b), …)
@integrate(f, x…, key = value…)

    The integral of the expression f, written without quoting: a convenience front end to integrate for Julia Exprs, so no symbolic package is needed. f is taken as an Expr in the variables, which are names; other names in f are parameters. Use $v to put in the value of a variable v. The bounds a, b and the keyword values are evaluated as usual.

    • x: the indefinite integral, an Expr (or an IntegralWithRootSums);

    • x, y, …: iterated, ∫ … (∫ f dx) dy …;

    • (x, a, b): definite, F(b) - F(a): a number when it evaluates to one, else an Expr (with parameters, or symbolic bounds). The bounds are evaluated, so a bound in a variable of a later integral is quoted: (x, 0, :y), (y, :(x^2), :x);

    • the keywords are passed on: build (default (op, args...) -> Expr(:call, nameof(op), args...)), lift (default identity), verify.

    using RischIntegrate
@integrate(x * exp(x), x)          # (-1 + x) * exp(x)
@integrate(sin(x), (x, 0, π))      # 2.0
@integrate(x^2 * y, x, y)          # (1//3 * x ^ 3) * (1//2 * y ^ 2)
@integrate(a * x^2, (x, 0, 1))     # a * (1//3 * 1 ^ 3) - a * (1//3 * 0 ^ 3): a parameter, an Expr
n = 3; @integrate(x^$n, x)         # 1//4 * x ^ 4
@integrate(sin(x), (x, 0, :b))     # -1 * cos(b) - -1 * cos(0): a symbolic bound, quoted
@integrate(x * y, (x, 0, :y), (y, 0, 1))   # 0.125: over the triangle 0 ≤ x ≤ y ≤ 1

    RischIntegrate.risch_integrate

    source 
    risch_integrate(f, x; build = nothing, lift = nothing, verify = true, signs = (), sign = nothing)

    The antiderivative of the term f in the variable x (the function behind integrate). build and lift control how the answer is built as a term; verify = false skips the final check of the answer by differentiation (every answer is checked by default). Returns a term, or an IntegralWithRootSums; throws NotElementary or RischNotImplemented.

    Some forms depend on the sign of an expression in the parameters (symbols other than x): atan or log, which square root. Signs can be given, as in GruntzLimit, by signs: pairs c => s, with c a parameter or an expression in the parameters written like f, and s one of :positive, :negative or :nonzero. GruntzLimit's :zero, :nonnegative and :nonpositive are an ArgumentError: a zero value is a special case of the parameters, which is not treated. The sign of an expression is then taken from a fact about a rational multiple of it, from the signs of its terms, or from a product of the facts' expressions. More generally, sign(p) is called with the expression p, a term built like the answer, and returns 1, -1, 0 or nothing (undecided); it is asked before signs. It is also asked about the argument w of each logarithm c log(w) in the answer (an expression in x, on the caller's domain): for -1 the answer has log(-w), real there. Otherwise log(w) stays, complex where w < 0 (it differs from a real antiderivative by a constant there, as in Mathematica's answers). Undecided signs are taken with the k-th parameter (alphabetically) set to k, or to -k when that parameter is known to be negative. A 0 for an expression that is not identically zero is a special case of the parameters, not treated (RischNotImplemented).

    risch_integrate(:(1/(x^2 + a)), :x; signs = Dict(:a => :negative))

    RischIntegrate.IntegralWithRootSums

    source 
    IntegralWithRootSums

    An antiderivative elementary + Σ rootsums (a term of the user's package plus RootSums, or TermRootSums for RootSums found inside a tower of exp/log monomials). F(a) evaluates it numerically at a real a and returns the real part (the real part of an antiderivative of a real integrand is an antiderivative too). The logarithms of a RootSum are continued along the real line from a fixed reference point (not principal values), so F is continuous wherever the integrand is finite and F(b) - F(a) is a definite integral.

    RischIntegrate.RootSum

    source 
    RootSum

    Σ_{Q(α)=0} α log W(α, x): poly is Q(z) (monic, squarefree; coefficients low → high) and W the coefficients of W(z, x) in x (low → high), each a polynomial in z reduced mod Q. var is how the variable prints and arg the term it stands for (after a substitution such as t = sqrt(1 + x) this is that term; nothing when it is the integration variable itself). Callable: rs(t) evaluates the sum numerically at the value t of its variable (complex roots, principal logarithms).

    RischIntegrate.TermRootSum

    source 
    TermRootSum

    Σ_{Q(α)=0} α log W(α) with W(α) = Σ_j coeffs[j] α^(j-1), the coeffs being terms of the user's package (a RootSum found inside a tower, e.g. in log(x)). rs(a) evaluates numerically at x = a.

    RischIntegrate.NotElementary

    source 
    NotElementary

    The integral was proved to have no elementary antiderivative (and no form with the special functions used by the package was found).

    RischIntegrate.RischNotImplemented

    source 
    RischNotImplemented

    The integrand lies outside the cases implemented: no answer, and no decision whether the integral is elementary.

    RischIntegrate.RischError

    source 
    RischError

    An internal error, e.g. an answer that failed its own check by differentiation. It indicates a bug.
